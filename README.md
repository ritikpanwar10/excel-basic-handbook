**Microsoft Excel** is a spreadsheet program developed by Microsoft, part of the Microsoft 365 (Office) suite. It organizes data into a grid of rows and columns to store, calculate, analyze, and visualize numeric and text data.

## 📌  Worksheet Limits

- **Total Columns:** 16,384 (Labeled A to XFD)

- **Total Rows:** 1,048,576 (Numbered 1 to 1,048,576)

- **Total Cells per Sheet:** ~17.18 Billion (`1,048,576 × 16,384`)

## 📌 Key Interface Components
- **Ribbon & Tabs:** The top toolbar holding all commands (`Home`, `Data`, `Formulas`, etc.).
- **Name Box:** Displays the address of the currently active cell (e.g., `C5`).
- **Formula Bar (`fx`):** Displays and allows editing of data or formulas stored in the active cell.
- **Active Cell:** The currently selected cell highlighted with a solid outline.
- **Status Bar:** Bottom bar showing quick aggregations (Average, Count, Sum) for selected cells.
